# M5.2 QR Provisioning Contract

Gather reuses the ODK Collect Settings QR format emitted by ODK Central. This
is not a Gather-specific format.

## Wire format

```text
base64(zlib_deflate(utf8(JSON.stringify(settings))))
```

Use standard padded base64 and zlib-wrapped DEFLATE, not raw DEFLATE. Decode in
the reverse order: base64 decode, zlib inflate, UTF-8 decode, JSON parse.

The decoded JSON requires all three top-level fields:

```json
{ "general": {}, "admin": {}, "project": {} }
```

`admin` must be present even when empty.

## Central App User provisioning

Central emits the App User configuration as:

```json
{
  "general": {
    "server_url": "https://<host>/v1/key/<APP_USER_TOKEN>/projects/<projectId>"
  },
  "project": { "name": "<project name>" },
  "admin": {}
}
```

Managed QR codes also include `form_update_mode: "match_exactly"` and
`autosend: "wifi_and_cellular"`.

The token in the `server_url` path is the App User credential. Treat both the
raw QR content and decoded configuration as secret material.

## Gather M5 scope

M5 treats this QR as **server/App User provisioning only**. It extracts:

- Central base URL;
- Central project ID;
- App User token;
- optional project display name.

It intentionally ignores Collect-specific UI, administration, autosend, and
form-update preferences. Gather does not adopt Collect's full-reconfigure
semantics for those settings.

## Parser contract

1. Base64-decode the raw QR text.
2. Zlib-inflate to UTF-8 with a maximum decompressed size of 64 KiB.
3. Parse JSON.
4. Require object-valued `general`, `admin`, and `project`.
5. Require `general.server_url`.
6. Match Central App User URLs:
   `https://<host>/v1/key/<token>/projects/<numeric-project-id>`.
7. Return extracted provisioning fields, never the raw QR content.

Reject malformed, non-Central, non-HTTPS, oversized, or otherwise unsupported
payloads with a user-safe error. Never log tokens, passwords, raw QR strings,
or decoded payloads. Do not persist the raw QR payload or image.

ODK Collect can also import plaintext `general.password` and `admin.admin_pw`
from non-Central configurations. M5 rejects those configurations rather than
handling their credentials.

## Gather implementation

- `src/provisioning/collectSettingsQr.js` parses the format above through an
  injected base64/zlib codec seam. The Expo codec uses zlib-wrapped DEFLATE and
  stops decompression at 64 KiB.
- The Setup QR screen uses VisionCamera QR scanning as the primary input and a
  secure paste field as a fallback. The scanner forwards only the first scanned
  string to the existing `actions.provisionQr()` path, does not parse it, and
  neither logs nor persists raw QR content.
- Before any local write, provisioning creates an `OdkCentralClient` with
  `createAppUserAuth(token)` and calls its public `listForms()` contract. A
  failed verification leaves SQLite, files, and SecureStore untouched.
- SQLite stores only project metadata. The App User token is held only in
  `CredentialStore`; neither Settings QR source/decoded content nor tokens are
  included in provisioning results or safe diagnostic objects.
- Project removal requires a confirmation. It reports draft/ready counts when
  supplied by the instance lifecycle, then removes credentials, the complete
  project directory, and project metadata. A failed cleanup is an explicit
  failure, never a removal success.

The opt-in live verification is `node --test test/live/provisioning.live.test.mjs`
with `ODK_CENTRAL_URL`, `ODK_CENTRAL_PROJECT_ID`, and
`ODK_CENTRAL_APP_USER_TOKEN` in the environment. It uses in-memory local
adapters, reads Central through the public client contract, and creates no
server-side data.

## VisionCamera QR scanning

`QrScanner` uses the installed VisionCamera barcode scanner with:

```jsx
<CodeScanner
  isActive={isActive}
  barcodeFormats={['qr-code']}
  onBarcodeScanned={onBarcodeScanned}
/>
```

It requests access through `useCameraPermission()` and pauses after the first
scan while provisioning completes. On error or a denied permission, the paste
fallback remains available.
